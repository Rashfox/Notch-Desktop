# 🖥️ Notch-Desktop

Hadirkan pengalaman interaktif ala **Dynamic Island / Notch** langsung ke layar desktop kamu! **Notch-Desktop** adalah aplikasi utilitas ringan yang mengubah bagian atas layar menjadi pusat kontrol cepat yang elegan dan fungsional.

![Release](https://img.shields.io/badge/version-v1.1.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

## ✨ Fitur Utama

* **🎵 Kontrol Media Cepat:** Lihat lagu yang sedang diputar lengkap dengan kontrol *Play/Pause*, *Next*, dan *Previous* tanpa perlu berpindah jendela.
* **🔔 Notifikasi Interaktif:** Tampilan notifikasi sistem yang mulus dan tidak mengganggu aktivitas utama.
* **⚡ Pemantauan Sistem:** Pantau status baterai, penggunaan CPU/RAM, atau koneksi secara sekilas *(sesuaikan dengan fitur aslimu)*.
* **🎨 Kustomisasi Fleksibel:** Atur ukuran, posisi, transparansi, dan animasi sesuai selera tampilan desktop kamu.
* **🪶 Ringan & Cepat:** Dirancang agar berjalan di latar belakang dengan konsumsi memori yang minimal.

## 🚀 Cara Instalasi

1. Buka halaman [Releases](https://github.com/Rashfox/Notch-Desktop/releases).
2. Unduh versi terbaru (**v1.1.0**) sesuai dengan sistem operasi kamu.
3. Ekstrak file (jika berbentuk `.zip`) dan jalankan aplikasi **Notch-Desktop**.
